## Описание работы
Данный репозиторий содержит материалы практической работы «Разработка руководства оператора» для учебного сервиса заявок (версия интерфейса 1.5.0). 

Цель работы — создать понятное и проверенное руководство для обычного сотрудника, который впервые пользуется сервисом заявок. В документе описаны действия операторов (создание и проверка заявок) и техников (взятие в работу и завершение).

## Состав репозитория
- [`operator_guide.md`](operator_guide.md) — основное руководство оператора и техника (сценарии, словарь терминов, ветви ошибок).
- [`role_matrix.md`](role_matrix.md) — матрица ролей (действия и ограничения оператора и техника).
- [`usability_test.md`](usability_test.md) — протокол аналитического испытания документа по модели интерфейса.
- [`change_log.md`](change_log.md) — история исправлений, внесенных в руководство после проверки.

## Краткие выводы
В ходе работы был проведен анализ целевой аудитории (операторы и техники), составлен словарь терминов и написано 5 самостоятельных сценариев с наблюдаемыми признаками результата. 
Испытание проходило в режиме аналитической проверки текста по модели интерфейса (ввиду отсутствия тестового стенда). В ходе проверки выявлены двусмысленные шаги, которые были исправлены и зафиксированы в файле `change_log.md`.
