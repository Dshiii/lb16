# Матрица ролей

Таблица описывает действия целевых ролей в учебном сервисе заявок версии 1.5.0. 
Административные действия (управление пользователями, сервером, базой данных) в руководстве не рассматриваются и выполняются через обращение в поддержку.

| Роль | Что может делать | Что видит в интерфейсе | Ограничения |
| :--- | :--- | :--- | :--- |
| **Оператор** (`operator_a`, `operator_b`) | Создавать заявки; читать свои заявки; редактировать свои открытые заявки. | Только свои заявки в списке (фильтр «Мои»). | Не видит чужие заявки. Не может удалять заявки. Не может менять статус на «В работе» или «Выполнено». |
| **Техник** (`technician_a`) | Читать назначенные ему заявки; переводить их в статус `in_progress` (кнопка «В работу»); завершать их со статусом `resolved` (кнопка «Отметить выполненной»). | Только заявки, назначенные на него (фильтр «Назначенные»). | Не может удалять заявки. Не может завершить заявку без обязательного комментария. Не видит неназначенные заявки. |

## Общие правила безопасности
- Доступ ограничивается на стороне сервера. Отсутствие кнопки в интерфейсе само по себе не является гарантией защиты.
- При попытке открыть чужую заявку по прямой ссылке пользователь видит экран «Нет доступа к этой заявке» и ссылку «К списку».
